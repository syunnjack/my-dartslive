# My Dartslive

ダーツ設置店を中心に、ボウリング、カラオケ、プリクラ、プライズ、ゲームセンターを横断検索するUGC対応アミューズ施設検索サービスです。

Canonical domain: https://syunnjack.github.io/my-dartslive/

## Features

- ジャンル・駅・条件検索
- 大会・イベント、クーポン、深夜営業、団体向けフィルター
- 設置情報、混雑、景品入荷、大会、閉店情報のUGC投稿
- SEO/AIO/LLMO向けFAQ、即答ブロック、構造化データ
- robots.txt / sitemap.xml / llms.txt
- 店舗送客、予約、クーポン、イベント告知、確認済み掲載、物販アフィリエイトの収益導線
